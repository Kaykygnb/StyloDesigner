# Código de conduta

Queremos um projeto em que qualquer pessoa — iniciante ou experiente — se sinta segura para perguntar, errar e contribuir.

**Esperamos:** respeito, paciência com quem está aprendendo, críticas ao código e não à pessoa, e acolhimento de quem escreve em português ou em inglês.

**Não toleramos:** assédio, insultos, discriminação de qualquer tipo, exposição de dados pessoais de outras pessoas e spam.

**Se algo der errado:** relate de forma privada à pessoa que mantém o projeto (veja o perfil do dono do repositório no GitHub). Comentários e contribuições que violem este código podem ser removidos, e a pessoa pode ser afastada do projeto.

Este texto é uma versão curta, inspirada no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), que vale como referência para situações não previstas aqui.
