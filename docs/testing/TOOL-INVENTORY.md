# Inventário verificável de ferramentas

Gerado por `npm run docs:inventario`; conferir sem escrever com `npm run docs:inventario -- --check`. Não editar registros manualmente. Catálogo: 120 ferramentas (97 núcleo, 23 plugins embutidos). Plugins só estão disponíveis quando habilitados.

[JSON completo](TOOL-INVENTORY.json) contém descrições/schemas reais, limites declarados no schema, origem, linhas e todas as referências. Fontes: catálogo, handlers, workspace e callers MCP/Studio. Não altera runtime.

## Limites da evidência

O gerador exige um handler estrutural por ferramenta e função run nos plugins. Isso verifica registro/ligação documental, não executa o handler nem prova resultado, autorização, undo ou atomicidade. Menções em testes são candidatas, nunca cobertura comprovada. Dependências listadas no JSON são referências diretas no corpo do handler; dependências transitivas/ambientais exigem revisão adicional. Limites imperativos/respostas exigem auditoria do handler e não estão todos no schema. Não transformar ausência de menção literal em ausência de testes.

Locks são políticas dos callers (não uma garantia para toda API); update_layers tem condição adicional de documento para resize/layout. Gate de acesso por conta/membro/grant é separado do escopo do agente. Workspace.PROJECT não passa pelo histórico normal do runner; export_zip requer escopo export e, antes disso, recusa o papel de projeto VIEWER sem gravar. Select/leituras podem mudar estado transitório sem gravar documento.

A matriz é a base de DOC-CORE-001, DOC-MCP-001 e DOC-STUDIO-001. Cada registro é conferido pelo teste de contrato tests/tool-inventory.test.js; isso não substitui testes comportamentais das famílias nem a futura matriz MCP/paridade. Cobertura comportamental por ferramenta não é certificada nesta entrega; consulte [a tarefa](../planning/tasks/core/DOC-CORE-001.md) e [regressões](REGRESSION-MATRIX.md).
