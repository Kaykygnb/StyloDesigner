# Relatórios de QA exploratório

Esta pasta está preparada para relatos reais futuros. **Ainda não há sessões exploratórias ou resultados registrados aqui.** O [modelo](../REPORT-TEMPLATE.md) é um formulário, não uma sessão executada.

O Work pode entregar o relato em texto/anexo ao proprietário; acesso de escrita ao GitHub não é requisito. O proprietário revisa evidências, autorização de divulgação e dados sensíveis antes de armazenar. Publicação por agente exige instrução explícita para o relatório/alvo. Não commitar credenciais, dados pessoais reais ou capturas que os revelem.

## Armazenamento

- Relatório: `docs/qa/reports/QA-RPT-AAAAMMDD-NNN.md`.
- IDs de sessão/relatório únicos: humano confere esta pasta e relatos pendentes antes de escolher o próximo NNN; UTC é a referência recomendada para a data do ID, com fuso real registrado no contexto.
- Evidências, se reais e autorizadas: `docs/qa/reports/QA-RPT-AAAAMMDD-NNN/evidence/`, ou armazenamento externo permitido. Nomes recomendados: `OBS-001-01.png`, `OBS-001-02.txt`; referenciar o caminho real no relatório e o que cada arquivo demonstra.
- Se o volume ou privacidade exigir outro armazenamento, usar link autorizado e registrar limitações de acesso/duração. Não criar arquivo fictício, nem usar a captura de outra sessão como evidência da sessão atual.
- Preservar observações originais e acrescentar histórico de revisão/triagem. Reteste usa novo relatório e aponta à evidência anterior; não substituir uma falha antiga por “passou”.
