# Plugins

Plugins fornecem capacidades complementares: identidade visual, assets, acessibilidade, Tailwind, SEO e QR Code.

## Controla

Registro de ferramentas complementares, providers, permissões declaradas e integração com recursos.

## Não deve fazer

Não deve contornar schema, autorização, sanitização ou persistência do core/servidor.

## Verificação

Testes de plugins, providers, biblioteca e busca de assets. Chaves reais continuam uma lacuna.
